# Reqon 0.13.4 — исправление Linux runtime

Падение `Fatal Python error: none_dealloc: deallocating None` в `drawBranches` совпадает с известной проблемой Linux-колёс PySide6 6.12.0 при работе с Python 3.11. В предыдущем архиве была именно эта комбинация. Вызов `QPainter.save()` в стеке указывает на место обнаружения повреждённого счётчика ссылок; сам по себе он не доказывает ошибку отрисовки дерева.

Разработчики Qt описывают проблему ABI и счётчиков ссылок в [PYSIDE-3424, заметки Qt for Python](https://wiki.qt.io/Qt_for_Python_Development_Notes). Практический случай падения на Python 3.11 и исключение версии 6.12.0 задокументированы в [зависимостях mlgidGUI](https://github.com/mlgid-project/mlgidGUI/blob/main/pyproject.toml).

В переносимом архиве заменён весь комплект Qt/PySide6/Shiboken, включая плагины, нативные библиотеки и Python-модули поддержки, на согласованную версию 6.11.3 из официальных колёс PyPI для Linux x86-64. Старый комплект 6.12.0 исключён из архива. В `requirements.txt` закреплена 6.11.3 для Linux с Python ниже 3.12. Windows-установщик остаётся 0.13.3.

Файл: `dist/Reqon-0.13.4-linux-x86_64.tar.gz`. Целевая система — ALT Linux 11 (p11), x86-64; минимальная glibc — 2.36. Python 3.11, gRPC и остальные зависимости переиспользованы из существующей Astra-сборки.

## Обновление

Закройте прежнюю версию. Распакуйте архив в новую папку, в которой ещё нет каталога `Reqon`, и запустите:

```sh
tar -xzf Reqon-0.13.4-linux-x86_64.tar.gz
./Reqon/reqon
```

Не копируйте новую `_internal` поверх старой: оставшиеся библиотеки другой версии могут конфликтовать. Рабочая база находится отдельно — `~/.local/share/Reqon/reqon.sqlite3` либо в `$XDG_DATA_HOME/Reqon`; при обычном запуске новая версия использует её автоматически. Если раньше задавался `--data-dir`, передайте тот же путь.

Полный набор тестов не запускался. Среда Linux на машине сборки недоступна, поэтому запуск на ALT Linux и отсутствие повторного падения во время работы пока не подтверждены. Версии и SHA-256 исходных колёс записаны в `build-info.json` внутри архива.
