# Reqon 0.13.2 — Astra Linux 1.8 x86-64

Linux теперь использует тот же интерфейс Qt Widgets, что и Windows: палитру Reqon, иконки `Reqon_Icon_Pack_Approved`, иллюстрации состояний `reqon-ui-states v2`, окружения, оформление коллекций, редактор и вкладки. Новая коллекция сразу создаётся как `New Collection` с выделенным названием в заголовке. Выравнивание переключателя окружений, тонкий разделитель, горизонтальная прокрутка и кнопка `+` также перенесены.

Иконки приложения и меню установлены из утверждённого набора. Имя Debian-пакета `getman`, каталог `/opt/getman` и пользовательская база `~/.local/share/Getman` сохранены для обновления существующей установки. Доступны команды `reqon` и `getman`.

Установка из папки с пакетом:

```bash
sudo apt install ./getman_0.13.2_astra1.8_amd64.deb
```

Для быстрой поставки использована прежняя нативная сборка Astra Linux 1.8 версии 0.11.0: Linux ELF, Python 3.11, библиотеки Qt и gRPC сохранены без изменений. Python-модули приложения обновлены целиком и скомпилированы для Python 3.11; добавлены новые ресурсы. Это обновление существующего Linux-пакета, выполненное скриптом `packaging/refresh-astra-package.py`, а не новая сборка нативных зависимостей.

Проверены компиляция и чтение всех модулей, встроенный архив, неизменность нативных библиотек, содержимое DEB, права файлов и ресурсы. Полный набор тестов не запускался. **Запуск новой версии в Astra Linux не проверен:** Docker на машине сборки не стартует из-за недоступной виртуализации.

Сведения о происхождении пакета и контрольных суммах: `dist/Reqon-0.13.2-linux-build-info.json`. SHA-256 находится рядом с `.deb`. Скрипт полноценной сборки в Astra `packaging/build-deb.sh` также обновлён и включает новые ресурсы.

Для обновления Python-архива использован штатный поиск последнего архива в [загрузчике PyInstaller 6.22.3](https://github.com/pyinstaller/pyinstaller/blob/v6.22.3/bootloader/src/pyi_archive.c). Исходный Linux ELF сохранён полностью; байткод подготовлен официальным Python 3.11.9 той же версии ABI.
