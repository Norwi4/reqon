# Reqon 0.13.1 для Windows

## Environments

Интерфейс переработан по скриншотам 19–25. Нажатие Environments в боковой панели открывает редактор окружения в обычной вкладке. Повторное открытие того же окружения выбирает существующую вкладку. Кнопка `+` создаёт новое окружение; над списком работает поиск. Globals открываются отдельно.

- Новое окружение содержит одну пустую строку `Add variable`. При начале взаимодействия с ней появляется следующая пустая строка. Последняя строка-подсказка не сохраняется как переменная.
- Таблица содержит Variable и Value. При наведении появляются точки для перемещения, флажок включения и удаление. Перетаскивание поддерживает прокрутку; соседние строки перемещаются с анимацией 160 мс. Кнопки Share нет.
- Имя, значения, флажки и порядок строк сохраняются автоматически. Перед закрытием вкладки или приложения изменения записываются без вопроса о сохранении. Открытые вкладки окружений восстанавливаются при следующем запуске.
- В списке при наведении доступны цвет, применение и меню. Палитра содержит готовые цвета, сброс и выбор своего цвета. Цвет отображается в списке, заголовке вкладки и селекторе активного окружения справа сверху. Изменение цвета сразу обновляет селектор.
- Галочка применяет окружение; повторное нажатие отключает его. Само открытие редактора не меняет выбранное окружение.
- Меню содержит Export, Move, Rename, Duplicate и Delete. Share, Copy link и Fork отсутствуют. **Move меняет порядок в локальном списке окружений**: облачных рабочих пространств в приложении нет.
- Экспорт и импорт используют JSON окружений с полями `name`, `values`, `_postman_variable_scope`. Порядок, отключённые строки и значения сохраняются; цвет переносится в расширении `_reqon`. Кнопка Import над списком импортирует окружение, когда открыт раздел Environments.

Переменные подставляются в HTTP/gRPC и команды curl/grpcurl. Приоритет от меньшего к большему: **Globals → переменные коллекции → выбранное окружение**. Отключённая переменная не перекрывает значение из предыдущего уровня. Изменения доступны запросам сразу, даже до срабатывания таймера записи на диск. Изменение применённых переменных сбрасывает зависимый кэш reflection.

## Коллекции

Выделение и Overview переработаны по скриншотам 26–27. Дерево показывает сплошное серое выделение с узкой оранжевой полосой слева, без синей рамки. Клик по названию коллекции открывает её вкладку и раскрывает дерево; стрелка позволяет свернуть его.

В Overview описание занимает основную область слева, а справа находятся фактические количества HTTP/gRPC-запросов и папок, а также Summary. Описание по-прежнему сохраняется автоматически. Вкладка Variables и действия добавления запросов, папок и экспорта сохранены.

## Хранение и совместимость

Данные остаются в `%APPDATA%/Getman/getman.sqlite3` или явно выбранном `--data-dir`. В Windows добавляется таблица `environment_details` для устойчивого идентификатора, цвета, порядка окружений и строк. Существующая таблица `environments` продолжает хранить словарь активных значений для совместимости. Globals сохраняются в `workspace_state`.

При первом переносе существующих окружений создаётся резервная копия `getman.before-0.13.1.sqlite3` рядом с рабочей базой. Старые имена и значения переносятся автоматически. Настройки TLS, комментарии JSON, коллекции и история сохраняются.

Изменения интерфейса и новой модели окружений включены только в Windows. Linux/Astra не пересобирались; версия других ОС остаётся 0.11.0.

- Отдельно проверена прежняя платформенная ветка без Windows-оформления и новой таблицы окружений. Реальный запуск Linux в этой задаче не выполнялся.
- PyInstaller и Inno Setup успешно собрали приложение и установщик. Проверены версия 0.13.1 в ресурсах EXE/установщика, системная иконка и включённые оригинальные ресурсы.

## Установка

Установщик: `dist/Reqon-Setup-0.13.1-win64.exe`. В мастере можно выбрать папку установки. Для запуска без установки доступен `dist/Reqon-windows.zip`: распакуйте весь архив и запустите `Reqon/Reqon.exe`.
