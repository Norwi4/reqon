# Reqon 0.13.3 для Windows

Исправлены оставшиеся пути и видимые названия Getman. Эта поставка включает только Windows; последняя готовая Linux-сборка остаётся 0.13.2.

- Установка по умолчанию: `%LOCALAPPDATA%\Programs\Reqon`. Если предыдущая папка называлась `Getman`, мастер предлагает соседнюю `Reqon`, в том числе для пользовательского пути `D:\Tools\Getman`. Другие выбранные пользователем папки сохраняются. Путь можно изменить вручную.
- Рабочие данные: `%APPDATA%\Reqon\reqon.sqlite3`. Кнопка **Local data** открывает этот каталог. Резервные копии схемы называются `reqon.before-*.sqlite3`.
- При первом запуске прежняя база из `%APPDATA%\Getman\Getman` или `%APPDATA%\Getman` копируется через SQLite backup. Переносятся коллекции, запросы, окружения, история, черновики и состояние вкладок. Учитываются изменения в WAL. База публикуется только после проверки целостности; исходная база остаётся на месте для восстановления. Существующая база Reqon никогда не заменяется.
- `--data-dir` сохраняет изоляцию рабочей области: переносится только старая база из указанной папки.
- Новые собственные экспорты имеют суффикс `.reqon_collection.json`; новые локальные ссылки — `reqon://`. Старые экспорты и ссылки `getman://` продолжают открываться. Внутренние маркеры формата `getman-collection-v1` и `x-getman` сохранены для совместимости со старыми версиями.
- Имя Qt-приложения, временные каталоги protobuf и название установочного скрипта обновлены на Reqon. AppId установщика и `Norwi4.Reqon` сохранены, чтобы обновление и ярлыки относились к тому же приложению.
- Установщик учитывает запущенную прежнюю версию при проверке занятых файлов. Пользовательская база не входит в файлы установки и удаления.

Проверки: 7 сценариев переноса данных (включая WAL, повреждённую базу, повторный запуск и пользовательскую папку), 13 проверок коллекций и 8 проверок окружений. Отдельный скомпилированный сценарий Inno Setup подтвердил новые пути, сохранение пользовательского каталога и предложенный путь `Programs\Reqon` для текущей старой установки; он завершился до установки и не менял её.

Установщик: `dist/Reqon-Setup-0.13.3-win64.exe`. Перенос реальных данных произойдёт при первом запуске установленной пользователем новой версии.
