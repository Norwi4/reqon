# Reqon 0.13.6 — сохранение запросов и экспорт коллекций

При переключении HTTP ↔ gRPC вкладка теперь сохраняет идентификатор запроса, коллекцию, папку и идентификатор черновика. Раньше она становилась отдельным черновиком, а в дереве оставалась прежняя запись. Исправление проверено закрытием вкладки и повторным открытием запроса из дерева.

Save и закрытие вкладки записывают полный текущий снимок: адрес, сервис/метод, тело, авторизацию, строки Headers/Metadata, включая отключённые, и настройки. Ручное сохранение читает поля после выбора коллекции, поэтому результат генерации сообщения, завершившейся во время диалога, также попадёт в запись. При ошибке записи вкладка остаётся открытой и не помечается сохранённой. Переключение протокола сохраняет Bearer, Basic/API Key и шаблоны переменных авторизации; gRPC передаёт их в Metadata.

Ранее отделённые черновики не удаляются: их можно открыть через **File → Open local draft** или поиск, затем сохранить в нужную коллекцию. Обновление не выбирает автоматически между несколькими черновиками с одинаковыми названиями.

## Экспорт выбранных коллекций

Нажмите кнопку со стрелкой вниз рядом с поиском коллекций, **File → Export collections…** или **Ctrl+Shift+E**. Откроется модальное окно с деревом и галочками у коллекций. Все коллекции выбраны по умолчанию; доступны **Select all** и **Clear selection**. Раскройте коллекцию для просмотра её папок, запросов и примеров.

**Export selected** создаёт один файл `*.reqon_collections.json` только с отмеченными коллекциями. В него входят полные запросы HTTP/gRPC, вложенные папки, примеры, переменные и описания коллекций, а также локальные protobuf-контракты, если они были заданы. Перед экспортом сохраняются последние изменения открытых вкладок. Запись файла выполняется атомарно.

Для обратного импорта используйте **Import → Import collection file…** либо **Ctrl+O**. Импорт всего набора выполняется одной транзакцией: ошибка в любой коллекции отменяет добавление всего набора. Одиночные файлы Postman/Reqon по-прежнему поддерживаются. Общий файл имеет собственный формат Reqon; для обмена отдельной HTTP-коллекцией с Postman остаётся прежний экспорт одной коллекции.

Собран установщик только для Windows: `Reqon-Setup-0.13.6-win64.exe`.
