Reqon / Возможности

Инструменты для работы с API

HTTP, gRPC, коллекции и окружения в нативном настольном приложении.

HTTP-запросы

Задайте метод и URL, добавьте параметры и отправьте запрос. Ответ, его статус и заголовки отображаются в том же окне.

  • Query-параметры, заголовки, JSON, текст и формы
  • Bearer, Basic и API Key
  • Импорт и экспорт cURL
  • HTTP/2, cookies и Proxy в Windows 0.13.8
Как отправить первый запрос

gRPC-сервисы

Находите методы через server reflection или импортируйте контракт сервиса. Редактируйте сообщение в JSON и просматривайте результат вызова.

  • Файлы .proto и descriptor set
  • Unary, server и client streaming
  • Metadata и trailers
  • TLS и клиентские сертификаты
  • Импорт и экспорт gRPCurl
Документация по gRPC

Коллекции и окружения

Храните связанные запросы вместе, создавайте вложенные папки и переключайте переменные между окружениями.

  • Коллекции, папки и история запросов
  • Переменные вида {{base_url}}
  • Автосохранение и ручное сохранение
  • Импорт HTTP-коллекций Postman v2.1
  • Формат Reqon для смешанных HTTP/gRPC-коллекций
