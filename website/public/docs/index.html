Установка

Windows x64

  1. Скачайте установщик для Windows.
  2. Запустите EXE и выберите папку установки.
  3. Откройте Reqon из меню «Пуск» или с рабочего стола.

Python отдельно устанавливать не нужно. Данные приложения находятся в %APPDATA%/Reqon.

Linux x86-64

Переносимому архиву нужна glibc ≥ 2.36 и графическая среда. Распакуйте его в новую папку и запустите приложение:

tar -xzf Reqon-<версия>-linux-x86_64.tar.gz
./Reqon/reqon

Сохраните папку _internal рядом с исполняемым файлом. Данные находятся в ~/.local/share/Reqon либо $XDG_DATA_HOME/Reqon.

Сборка 0.13.4 подготовлена для ALT Linux 11. Запуск на этой системе пока не подтверждён тестами; подробности есть в описании релиза.

Astra Linux 1.8

Скачайте DEB-пакет и установите его через APT, указав имя скачанного файла:

sudo apt install ./<имя-файла>.deb

В пакете 0.13.2 сохранён прежний комплект Qt. Если возникает ошибка none_dealloc, используйте переносимую Linux-сборку 0.13.4 при совместимой glibc.

Первый HTTP-запрос

  1. Создайте HTTP-запрос через New.
  2. Выберите метод GET и укажите адрес своего API.
  3. При необходимости добавьте параметры, заголовки и авторизацию.
  4. Нажмите Send и изучите тело, статус и заголовки ответа.
  5. Сохраните запрос в коллекцию, чтобы вернуться к нему позже.

Для адреса сервиса можно использовать переменную, например {{base_url}}/health.

Работа с gRPC

Создайте gRPC-запрос и введите адрес сервера. Если сервер поддерживает reflection, Reqon загрузит список сервисов и методов. Иначе импортируйте файл .proto или descriptor set.

  1. Выберите сервис и метод.
  2. Заполните JSON-сообщение или нажмите Use Example Message.
  3. Укажите metadata и параметры TLS, если они требуются серверу.
  4. Нажмите Invoke и изучите ответ, Metadata и Trailers.

Для client-streaming передайте JSON-массив сообщений. Настройки сертификатов доступны через замочек у адреса и вкладку Settings.

Коллекции и окружения

Создавайте коллекции и папки для связанных запросов. В разделе Environments добавьте переменные и выберите окружение перед отправкой.

HTTP-коллекции импортируются и экспортируются в формате Postman v2.1. Для gRPC и смешанных коллекций используйте .reqon_collection.json: в него включается descriptor set.

Коллекции и история хранятся на устройстве. Чтобы перенести данные, экспортируйте коллекцию и импортируйте файл на другом компьютере. Перед передачей файла проверьте его содержимое: заголовки и переменные могут содержать ключи доступа.

Проверка SHA-256

На странице загрузки откройте «SHA-256» и сравните значение с результатом команды для скачанного файла.

Windows / PowerShell

Get-FileHash .\Reqon-Setup-<версия>-win64.exe -Algorithm SHA256

Linux

sha256sum Reqon-<версия>-linux-x86_64.tar.gz

Все 64 символа должны совпасть. Если они отличаются, скачайте файл заново.

Обновление

Закройте приложение перед установкой новой версии. Для Windows запустите новый установщик. В Linux распакуйте новую сборку в отдельную папку: не смешивайте файлы разных версий.

Рабочие данные хранятся отдельно от приложения. Перед переходом на более старую версию сохраните резервную копию данных: совместимость новых данных со старыми версиями не гарантируется.
