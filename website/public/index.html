HTTP и gRPC

Работайте с REST API и gRPC-сервисами. Настраивайте параметры, заголовки и тело запроса, просматривайте статус и содержимое ответа.

Авторизация и соединение

Используйте Bearer, Basic и API Key для HTTP. Настраивайте TLS, клиентские сертификаты, metadata и параметры Proxy.

Коллекции и окружения

Группируйте запросы по проектам. Храните адреса и переменные в окружениях, переключайте их без изменения каждого запроса.

Исследуйте gRPC-сервисы

Reqon получает список сервисов и методов через reflection. Если reflection недоступен, загрузите файл .proto или descriptor set.

Отправляйте JSON-сообщения, проверяйте metadata и trailers. Поддерживаются unary и streaming RPC.

Сохраняйте запросы
в контексте проекта

Коллекции, папки и история помогают возвращаться к уже выполненным запросам. Переменные окружения позволяют использовать один запрос с разными адресами и параметрами.

Данные хранятся на устройстве. Для переноса на другой компьютер используйте импорт и экспорт коллекций.
