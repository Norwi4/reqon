Reqon 0.13.4 — переносимая сборка Linux x86-64

Целевая система: ALT Linux 11 (p11), x86-64.
Минимум: glibc 2.36, графическая сессия X11 либо Wayland,
системные графические библиотеки OpenGL/EGL и шрифты.
Python, Qt и gRPC включены в архив. Отдельный Python не требуется.

Распакуйте весь архив в новую папку и запустите:

    tar -xzf Reqon-0.13.4-linux-x86_64.tar.gz
    ./Reqon/reqon

Можно также запустить нативный исполняемый файл ./Reqon/Reqon.
Не распаковывайте поверх предыдущей версии: в 0.13.4 полностью заменён
комплект Qt/PySide6/Shiboken, и старые файлы _internal смешивать с ним нельзя.
Не перемещайте его отдельно от папки _internal.
При распаковке через tar права на запуск сохраняются.
Если архив распакован другим способом и права потеряны:

    chmod +x Reqon/Reqon Reqon/reqon

Установка пакетов и права root для самого приложения не нужны.
При ошибке платформенного плагина в сессии Wayland можно использовать XWayland:

    QT_QPA_PLATFORM=xcb ./Reqon/reqon

Рабочая база: ~/.local/share/Reqon/reqon.sqlite3 либо $XDG_DATA_HOME/Reqon.
Старые данные Getman копируются автоматически при первом запуске,
если рабочей базы Reqon ещё нет. Исходная база сохраняется.
Для отдельной рабочей области:

    ./Reqon/reqon --data-dir /путь/к/рабочей-папке

Архив не зависит от RPM/DEB, но не является статическим бинарником
для любой версии Linux. ALT 10, Ubuntu 22.04 и другие системы с glibc
ниже 2.36 этой сборкой не поддерживаются. ARM/AArch64 не поддерживается.

В 0.13.4 Qt/PySide6/Shiboken заменены согласованным комплектом 6.11.3.
Это устраняет использование PySide6 6.12.0, для Linux-колёс которого
на Python 3.11 описано падение none_dealloc при вызовах методов Qt.
Python 3.11, gRPC и остальные нативные зависимости сохранены из прежней
сборки Astra Linux. Полный набор тестов и запуск на ALT Linux не выполнялись.
Результат исправления нужно подтвердить при работе на целевой системе.
