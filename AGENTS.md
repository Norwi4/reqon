# Reqon: правила выпуска

Пользователь утвердил это оформление установщика 17 ноября 2026 года.
Применяйте его ко всем будущим релизам, пока пользователь не попросит изменить:

- Светлая тема установщика Windows, логотип Reqon и золотые акценты.
- Разработчик и издатель: **Reqon**. Сайт: `https://reqon.ru/`.
- Основа: `packaging/reqon.iss`; фирменная панель: `packaging/branding/wizard-light.png`.
  SVG и `render.py` в той же папке позволяют заново собрать панель из штатного логотипа и шрифтов проекта.
- Имя публикуемого установщика: **`Reqon-Setup-<version>.exe`**.
  Не добавляйте `light`, `dark`, `preview` или `win64` в имя релизного установщика.
- Сохраняйте эту тему и имя в скриптах сборки, публикации, ссылках скачивания и SHA-256-манифестах.
- При замене установщика в существующем релизе обновляйте его контрольную сумму и ссылки.
  Не меняйте идентификатор приложения: он нужен для обновления существующих установок.
- Встроенное обновление установленной Windows-версии использует стабильный GitHub Release,
  установщик с указанным выше именем и `Reqon-<version>-SHA256SUMS.txt`.
  Сначала загрузите и проверьте все файлы релиза, затем публикуйте его; не публикуйте неполный релиз.
- Упакованные Windows EXE должны содержать `packaging/reqon.manifest` с `asInvoker`.
  Его встраивает и проверяет `scripts/embed-windows-manifest.ps1`. Без этого Windows
  блокирует запуск копии `Reqon-update-helper.exe` с ошибкой 740. Проверяйте запуск
  помощника из обычного, не повышенного процесса; не заменяйте исправление запуском от администратора.
