# Reqon 0.21.1 — исправления gRPC

Исправлен отказ выполнения gRPC-запросов с ошибкой `invalid type: map, expected a 64-bit signed integer or decimal string`. Исправления доступны в GUI и CLI для Windows x64 и Linux x86_64.

## Что изменилось

- Стандартные protobuf-обёртки (`Int64Value`, `StringValue`, `BoolValue` и другие) принимают как обычные JSON-значения, так и объекты `{"value": …}`. Поддерживаются вложенные сообщения, массивы, словари и потоковые запросы; точность 64-битных целых сохраняется.
- **Generate example message** создаёт шаблон с вложенными сообщениями, обёртками и необязательными полями. Рекурсивные схемы обрабатываются с ограничением глубины; для `oneof` выбирается одно поле.
- Кнопка генерации сама загружает определения сервиса, если список методов ещё не открывался. Ошибки загрузки и отсутствие метода показываются пользователю. Изменения текста, сделанные во время загрузки схемы, сохраняются.

## Скачать и обновиться

- **Windows — установщик:** `Reqon-Setup-0.21.1-win64.exe`. Закройте Reqon и запустите установщик; существующая папка установки и пользовательские данные сохраняются.
- **Windows — ZIP:** `Reqon-0.21.1-windows-x86_64.zip`, содержит GUI и CLI.
- **Windows — отдельный CLI:** `Reqon-CLI-0.21.1-windows-x86_64.zip`.
- **Linux — DEB:** `reqon_0.21.1_amd64.deb`. Обновление: `sudo apt install ./reqon_0.21.1_amd64.deb`.
- **Linux — TAR.GZ:** `Reqon-0.21.1-linux-x86_64.tar.gz`. Распакуйте архив и запустите `./Reqon/reqon` или `./Reqon/reqon-cli`.

Linux-пакеты содержат GUI и CLI и предназначены для Debian 12+ / Ubuntu 24.04+. Контрольные суммы всех пакетов находятся в `Reqon-0.21.1-SHA256SUMS.txt`; отдельные списки сумм Linux и Windows CLI также приложены к релизу.

Формат коллекций и профиля не менялся. Пользовательские коллекции, настройки и секреты в состав пакетов не входят.

## Проверки

Пройдено 226 тестов библиотеки. Ошибка воспроизведена до исправления и устранена на локальном gRPC-сервере: проверены reflection, локальные `.proto`-схемы, обычные и потоковые запросы, генерация примеров и сохранение правок во время загрузки схемы.
