# Reqon 0.23.4 — единый стиль главного меню

- Главное меню в левом верхнем углу оформлено так же, как меню коллекций и окружений: шрифт Inter, компактные строки, единые отступы, подсветка и разделители.
- У каждого действия появилась контурная SVG-иконка. Дорисованы значки открытия коллекции и проверки обновлений.
- Сочетания клавиш выровнены в отдельной колонке справа. Поддерживается навигация стрелками, Home/End и выбор через Enter.

В установленной версии 0.23.2 или новее откройте **Menu → Check for updates → Update and restart**. После перезапуска в **About** будет указана **0.23.4**.

Сохраняются запуск помощника без повышения прав, светлая тема установщика, логотип, золотые акценты и издатель Reqon. Выпуск содержит Windows-установщик, архив GUI + CLI, отдельный архив CLI и контрольные суммы. Последняя сборка Linux — [0.22.0](https://github.com/Norwi4/reqon/releases/tag/v0.22.0).
