# Reqon 0.23.1 — проверка обновления из приложения

Небольшой выпуск для Windows, чтобы проверить переход с установленной версии 0.23.0 через встроенное обновление. Изменены номер версии и описание выпуска; поведение приложения сохранено.

## Обновление с 0.23.0

1. Откройте установленный Reqon 0.23.0.
2. Выберите **Menu → Check for updates** или **Preferences → About → Check for updates**.
3. Убедитесь, что доступна версия **0.23.1**, и нажмите **Update and restart**.
4. После скачивания, проверки SHA-256 и сохранения данных Reqon установит обновление и снова откроется. В **About** будет указано **0.23.1**.

Если остались активные запросы или сеансы терминала, завершите их и нажмите **Restart and update**. Рабочие пространства и черновики сохраняются.

При обновлении с 0.22.0 или более ранней версии установите [Reqon-Setup-0.23.1.exe](https://github.com/Norwi4/reqon/releases/download/v0.23.1/Reqon-Setup-0.23.1.exe) один раз обычным способом. Следующие версии можно устанавливать из приложения.

В комплекте — Windows-установщик, архив GUI + CLI, отдельный архив CLI и контрольные суммы. Сохраняются светлая тема установщика, логотип, золотые акценты и издатель Reqon. Последняя сборка Linux остаётся в [релизе 0.22.0](https://github.com/Norwi4/reqon/releases/tag/v0.22.0).
