# Reqon 0.15.0

- Раздел **Themes** в настройках с предпросмотром и выбором 12 тем: Light, Dark, High Contrast Light, High Contrast Dark, Ayu Light, Ayu Dark, Dracula, Monokai, Night Owl Light, Night Owl Dark, Solarized Light и Solarized Dark.
- Режим **Sync with system** с отдельным выбором дневной и ночной темы и автоматическим переключением при изменении оформления системы.
- Применение темы без перезапуска приложения и сохранение выбранного оформления между запусками.
- Адаптация редакторов, меню, цветовой маркировки HTTP-методов, иконок и иллюстраций к выбранной теме.
- Единый шрифт **Inter** для коллекций, папок, названий запросов, поля хоста и списка сервисов и методов gRPC. Шрифт редакторов кода настраивается отдельно.

В Assets доступны установщик EXE и переносимая ZIP-сборка для Windows x64. Контрольные суммы файлов находятся в SHA256SUMS.txt.
