# Reqon 0.23.0 — обновление из приложения

Установленная Windows-версия умеет проверять обновления и устанавливать их с перезапуском Reqon.

- Откройте **Menu → Check for updates** или **Preferences → About → Check for updates**.
- Если доступна новая стабильная версия, нажмите **Update and restart**. Reqon скачает установщик, проверит размер и SHA-256 и сохранит рабочие пространства и черновики перед перезапуском.
- Установка проходит в фоне; Reqon снова откроется с прежним каталогом данных. Запущенные запросы, CLI-команды и другие операции не завершаются принудительно.
- Скачивание можно отменить. Ошибки сети, контрольной суммы и установки отображаются в приложении.
- Встроенная установка предназначена для Windows-копии, установленной через официальный установщик. Linux, portable- и development-сборки получают ссылку на релиз.

Чтобы впервые получить эту функцию, установите `Reqon-Setup-0.23.0.exe` поверх прежней версии. Следующие обновления можно запускать внутри приложения.

Сохраняются светлая тема установщика, логотип, золотые акценты и издатель Reqon. Коллекции и пользовательские данные в установщик не включаются.
