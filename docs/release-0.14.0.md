# Reqon 0.14.0

- Редактирование cURL и gRPCurl в боковой панели с автоматическим применением изменений к текущему запросу.
- Сворачивание боковой панели повторным нажатием на активный раздел.
- Вкладка **Auth** с отдельными формами Basic Auth, Bearer Token, API Key и JWT Bearer. Для JWT доступны выбор алгоритма, payload, дополнительные заголовки и передача токена в заголовке или query-параметре.
- Раскрываемый список автоматически создаваемых HTTP-заголовков с возможностью отключить необязательные заголовки.
- Режимы Body: form-data с текстовыми полями и файлами, x-www-form-urlencoded, raw с выбором формата и форматированием JSON/XML, binary и GraphQL.
- Редакторы GraphQL-запроса и переменных. При выборе GraphQL метод автоматически меняется на POST; уведомление появляется только при смене метода.
- Расширенные настройки HTTP: перенаправления, сохранение метода и Authorization, обработка Referer, cookie jar, кодирование URL, строгая проверка заголовков ответа и параметры TLS.
- Консоль запросов в нижней части окна с фильтром, очисткой, копированием и изменением размера.
- Оранжевая кнопка **Info** с версией приложения и ссылкой на GitHub Issues.
- Обновлённая иконка настроек.

В Assets доступны установщик EXE и переносимая ZIP-сборка для Windows x64. Контрольные суммы файлов находятся в SHA256SUMS.txt.
