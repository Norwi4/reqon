# Reqon 0.23.2 — исправление запуска обновления в Windows

Исправлена ошибка **Could not launch the updater: ... (os error 740)** при обновлении из приложения.

Windows могла считать вспомогательный EXE установщиком, требующим повышения прав. В Windows-сборки добавлен явный манифест `asInvoker`: Reqon и помощник обновления работают с правами текущего пользователя. Упаковка проверяет наличие этого режима в готовом EXE.

## Если уже установлена 0.23.0 или 0.23.1

Из-за ошибки в старом помощнике один раз установите [Reqon-Setup-0.23.2.exe](https://github.com/Norwi4/reqon/releases/download/v0.23.2/Reqon-Setup-0.23.2.exe) обычным способом поверх прежней версии. После этого следующие выпуски можно устанавливать через **Menu → Check for updates → Update and restart**.

Рабочие пространства и черновики сохраняются. Светлая тема установщика, логотип, золотые акценты и издатель Reqon остаются прежними. Выпуск содержит Windows-установщик, архив GUI + CLI, отдельный архив CLI и контрольные суммы. Последняя сборка Linux — [0.22.0](https://github.com/Norwi4/reqon/releases/tag/v0.22.0).
