# Reqon 0.13.9

- Цветовая маркировка HTTP-методов в поле запроса, выпадающем меню и списке коллекций.
- Обновлённое меню HTTP-методов: открывается под полем, сохраняет видимость текущего метода и поддерживает выбор клавиатурой.
- Ввод собственного HTTP-метода с сохранением в запросе.
- Обновлённые иконки HTTP и gRPC во вкладках и меню выбора типа запроса.
- Обновлённое оформление переключателя HTTP/gRPC.
- Единая актуальная версия для Windows x64, Linux x86-64 и Astra Linux 1.8.
- В Linux доступны настройки General, HTTP/2, cookies, Proxy, импорт cURL/gRPCurl и проверка тела запроса по JSON Schema.

Установщики и переносимые сборки находятся в разделе Assets. Файл SHA256SUMS.txt содержит контрольные суммы загрузок.
