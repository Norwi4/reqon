# Reqon 0.22.0 — автозаголовки и навигация

Автоматические HTTP-заголовки теперь можно раскрывать, редактировать и отключать прямо в таблице Headers. В боковой панели появились переключение между коллекциями и окружениями и отдельное дерево окружений.

## Что изменилось

- Автозаголовки по умолчанию скрыты за счётчиком `N hidden`. Они раскрываются в общей таблице рядом с пользовательскими заголовками.
- Значения `Host`, `Cache-Control`, `User-Agent`, `Accept`, `Accept-Encoding`, `Connection` и `Content-Type` можно изменять, в том числе через переменные, отключать флажком и сбрасывать к автоматическим значениям.
- Отключение учитывается при реальной отправке: HTTP-библиотека больше не возвращает отключённые заголовки. Явно заданные пользовательские заголовки имеют приоритет.
- Настройки сохраняются с запросом в `.req`, YAML и профиле, учитываются в GUI, CLI и cURL. При импорте cURL сохраняется различие между отключённым и намеренно пустым заголовком.
- `Content-Length` рассчитывается по фактическому телу запроса; заголовки авторизации настраиваются во вкладке Auth. В HTTP/2 транспорт продолжает формировать обязательное поле `:authority`.
- Левая панель переключает Collections и Environments. Дерево окружений объединяет Globals, окружения рабочего пространства и коллекций; поддерживает поиск, создание, импорт и сворачивание групп. Редактор выбранного окружения использует всю ширину рабочей области.

## Скачать и обновиться

- **Windows — установщик:** `Reqon-Setup-0.22.0.exe`. Закройте Reqon и запустите установщик; существующая папка установки и пользовательские данные сохраняются.
- **Windows — ZIP:** `Reqon-0.22.0-windows-x86_64.zip`, содержит GUI и CLI.
- **Windows — отдельный CLI:** `Reqon-CLI-0.22.0-windows-x86_64.zip`.
- **Linux — DEB:** `reqon_0.22.0_amd64.deb`. Обновление: `sudo apt install ./reqon_0.22.0_amd64.deb`.
- **Linux — TAR.GZ:** `Reqon-0.22.0-linux-x86_64.tar.gz`. Распакуйте архив и запустите `./Reqon/reqon` или `./Reqon/reqon-cli`.

Linux-пакеты содержат GUI и CLI и предназначены для Debian 12+ / Ubuntu 24.04+. Контрольные суммы всех пакетов находятся в `Reqon-0.22.0-SHA256SUMS.txt`; отдельные списки сумм Linux и Windows CLI также приложены к релизу.

Пользовательские коллекции, профили и секреты в состав пакетов не входят. Обновление не требует переноса данных в новый формат.

17 ноября 2026 года установщик Windows обновлён: светлая тема, логотип Reqon, золотые акценты и сведения об издателе Reqon. Версия приложения остаётся `0.22.0`.
