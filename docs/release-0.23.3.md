# Reqon 0.23.3 — проверка обновления с 0.23.2

Небольшой выпуск для Windows с новым номером версии для проверки встроенного обновления. Поведение приложения сохранено, включая исправление ошибки 740: Reqon и помощник запускаются с правами текущего пользователя.

В установленной **0.23.2** откройте **Menu → Check for updates**, затем нажмите **Update and restart**. После установки и перезапуска в **About** будет указана **0.23.3**. Рабочие пространства и черновики сохраняются.

Для исходных 0.23.0 и 0.23.1 со старым помощником один раз установите [Reqon-Setup-0.23.3.exe](https://github.com/Norwi4/reqon/releases/download/v0.23.3/Reqon-Setup-0.23.3.exe) обычным способом поверх прежней версии.

Сохраняются светлая тема установщика, логотип, золотые акценты и издатель Reqon. Выпуск содержит Windows-установщик, архив GUI + CLI, отдельный архив CLI и контрольные суммы. Последняя сборка Linux — [0.22.0](https://github.com/Norwi4/reqon/releases/tag/v0.22.0).
