# Reqon 0.13.5 — импорт cURL и gRPCurl

В панели рабочего пространства нажмите **Import**, вставьте команду и нажмите **Import request**. То же окно доступно по **Ctrl+Shift+I** и кнопке **Import** в панели **Code snippet**. Импорт создаёт новую вкладку и сразу сохраняет локальный черновик. Другие открытые запросы остаются на месте. Файлы коллекций по-прежнему доступны через **Import collection file…** или **Ctrl+O**.

Для cURL заполняются HTTP-метод, адрес, Params, Headers, Authorization и Body. Поддержаны JSON, raw и URL-encoded тела, повторяющиеся query-параметры, Basic/Bearer, cookies, пользовательские методы, `--get`, `--head`, `--json`, `--data-raw`, `--data-binary` с текстом и `--data-urlencode`. Исходное кодирование query сохраняется до редактирования Params. Вкладка HTTP **Settings** позволяет менять проверку TLS-сертификата, автоматические перенаправления, таймаут и пути PEM-сертификатов. Эти настройки сохраняются с запросом и отражаются в экспортируемой команде cURL.

Для gRPC используется команда **grpcurl**: импортируются хост, сервис, метод, Message, Metadata, Bearer-авторизация, TLS, пути сертификатов/descriptor set и поддерживаемые настройки вызова. Последовательность JSON-сообщений преобразуется в массив для клиентского streaming.

Многострочные команды Bash, Windows CMD и PowerShell распознаются автоматически по переносу строки; для неоднозначных команд можно выбрать оболочку вручную. Поддержаны Bash ANSI-C строки `$'…'`. Окно показывает тип и адрес запроса до импорта.

Команды не исполняются, файлы не читаются и сетевые запросы во время импорта не отправляются. Значения переменных оболочки не вычисляются; используйте значения или переменные Reqon `{{name}}`. Неподдерживаемые параметры, несколько URL, multipart/file uploads, stdin, shell pipes и ссылки на тело `@file` вызывают понятное сообщение вместо создания частично заполненного запроса. Пути сертификатов и descriptor set используются позже при отправке/загрузке контракта.

Документация форматов: [curl](https://curl.se/docs/manpage.html), [grpcurl](https://github.com/fullstorydev/grpcurl).

Собран только Windows-установщик `Reqon-Setup-0.13.5-win64.exe`. Linux-архив 0.13.4 остаётся прежним.

Проверены разбор команд, заполнение вкладок, сохранение и восстановление, экспорт/импорт коллекции, реальные HTTP/HTTPS/gRPC-вызовы на локальных серверах и существующий генератор команд. Готовый EXE дважды запущен и штатно закрыт с временной рабочей базой; версии и SHA-256 установщика сохранены в `dist/Reqon-0.13.5-build-info.json`.
